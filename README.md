My Project of Learning – JavaScript

Repositorio personal de aprendizaje y práctica de JavaScript, en el que recopilo ejercicios realizados durante mi formación práctica y guiada con una academia (Mentor).

El objetivo de este proyecto es consolidar los fundamentos de programación, mejorar mi capacidad de resolución de problemas y adquirir buenas prácticas de escritura de código (Clean Code).

Actualmente estoy realizando una formación práctica centrada en JavaScript, trabajando progresivamente desde los fundamentos del lenguaje hasta la programación funcional y la manipulación de datos.

2. Métodos funcionales de arrays

Práctica progresiva de los principales métodos funcionales de JavaScript:

filter(): selección de elementos según determinadas condiciones.

map(): transformación de elementos.

reduce(): acumulación, sumas y cálculos.

find(): búsqueda de elementos.

Combinación de métodos para resolver problemas con arrays de objetos y estructuras anidadas.

Los ejercicios están organizados por niveles de dificultad, incluyendo retos de integración para aplicar los conocimientos adquiridos.
